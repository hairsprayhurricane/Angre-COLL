# Task Manager - Полнофункциональное приложение для управления задачами

Приложение состоит из двух частей: серверной (backend) и клиентской (frontend). Серверная часть написана на Node.js с Express и SQLite базой данных, клиентская часть - на React.

## Структура проекта

```
task-manager-fullstack/
├── backend/                 # Серверная часть (API)
│   ├── server.js           # Основной файл сервера
│   ├── db.js              # Подключение к базе данных
│   ├── tasks.db           # Файл базы данных SQLite
│   ├── package.json       # Зависимости серверной части
│   ├── README.md          # Документация серверной части
│   └── COMMANDS.txt       # Примеры SQL команд (старый файл)
├── frontend/               # Клиентская часть (React)
│   ├── src/               # Исходный код React
│   │   ├── components/    # React компоненты
│   │   ├── App.jsx        # Главный компонент
│   │   └── index.js       # Точка входа
│   ├── public/            # Статические файлы
│   ├── package.json       # Зависимости клиентской части
│   └── README.md          # Документация клиентской части
├── package.json           # Корневой файл с командами
└── README.md             # Вы здесь
```

## Что умеет приложение

### Серверная часть (Backend)
- Создание, чтение, обновление и удаление задач
- REST API для работы с задачами
- База данных SQLite для хранения данных
- Валидация входящих данных
- Обработка ошибок

### Клиентская часть (Frontend)
- Современный интерфейс на React
- Добавление новых задач
- Редактирование существующих задач
- Изменение статуса задач
- Удаление задач с подтверждением
- Статистика по задачам
- Адаптивный дизайн для разных устройств

## Быстрый старт

### 1. Установка всех зависимостей
```bash
npm run install-all
```

### 2. Запуск всего приложения
```bash
npm start
```

Это запустит одновременно:
- Сервер на http://localhost:3069
- Веб-интерфейс на http://localhost:3000

### 3. Альтернативные способы запуска

#### Только сервер
```bash
npm run backend
```

#### Только веб-интерфейс
```bash
npm run frontend
```

## API для работы с задачами

 Метод  Адрес  Описание 

 GET  `/api/tasks`  Получить все задачи 
 GET  `/api/tasks/:id`  Получить задачу по ID 
 POST  `/api/tasks`  Создать новую задачу 
 PATCH  `/api/tasks/:id`  Обновить задачу 
 DELETE  `/api/tasks/:id`  Удалить задачу 

## Технологии

### Серверная часть
- Node.js - среда выполнения JavaScript
- Express.js - веб-фреймворк
- SQLite3 - база данных
- REST API - архитектура для API

### Клиентская часть
- React 18 - библиотека для создания пользовательских интерфейсов
- CSS3 - стилизация
- Fetch API - для HTTP запросов
- Адаптивный дизайн - для работы на разных устройствах

## Доступные команды

 Команда  Описание 
-------------------
 `npm start`  Запустить сервер и веб-интерфейс одновременно 
 `npm run backend`  Запустить только сервер 
 `npm run frontend`  Запустить только веб-интерфейс 
 `npm run install-all`  Установить все зависимости 
 `npm run build`  Собрать веб-интерфейс для продакшена 

## Примеры использования

### Создание задачи через API
```bash
curl -X POST http://localhost:3069/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Новая задача", "description": "Описание задачи"}'
```

### Получение всех задач
```bash
curl http://localhost:3069/api/tasks
```
