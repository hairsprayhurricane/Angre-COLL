# Клиентская часть Task Manager

React приложение для управления задачами, работающее с серверным API.

## Возможности

- Просмотр списка всех задач
- Добавление новых задач
- Редактирование существующих задач
- Изменение статуса задач (В процессе / Завершено)
- Удаление задач
- Статистика по задачам
- Адаптивный дизайн

## Структура компонентов

### App.jsx
Главный компонент приложения, который:
- Управляет состоянием всех задач
- Обрабатывает взаимодействие с API
- Координирует работу дочерних компонентов

### TaskForm.jsx
Компонент формы для добавления новых задач:
- Валидация введенных данных
- Отправка запросов на сервер
- Очистка формы после успешного добавления

### TaskList.jsx
Компонент списка задач:
- Отображение всех задач
- Показ статистики (количество задач по статусам)
- Обработка состояний загрузки и пустого списка

### TaskItem.jsx
Компонент отдельной задачи:
- Отображение информации о задаче
- Режим редактирования
- Изменение статуса задачи
- Удаление задачи с подтверждением

## Интеграция с API

Приложение использует следующие адреса:

- `GET /api/tasks` - получение всех задач
- `POST /api/tasks` - создание новой задачи
- `PATCH /api/tasks/:id` - обновление задачи
- `DELETE /api/tasks/:id` - удаление задачи

## Установка и запуск

### Из корневой папки проекта
```bash
npm run frontend
```

### Из папки frontend
```bash
cd frontend
npm install
npm start
```

Важно: Убедитесь, что серверная часть запущена на порту 3069

Приложение будет доступно по адресу: http://localhost:3000
